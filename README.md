# 오늘의 시간 여행

초등 5학년 한국사 차시별 게임 (아이스크림 사회 5-2 차시 순서)

- 사이트: https://52-timetravel.github.io/
- 한 차시를 세 단계로 써요: 🧭 떠나기(수업 전 · 시간 여행) → 📊 배워보기(수업 중 · 선생님) → 🏠 돌아오기(수업 후 · 귀환 퀴즈)
- 설치·로그인·회원가입 없음. 학생 점수는 선생님이 「선생님 설정」에서 연결한 **선생님 본인의 구글 설문지**로만 가요.
- 교과서 차시 순서대로, 실제 수업 진도에 맞춰 만들고 있어요.

## 저작권
- 교과서 사진·삽화는 쓰지 않았어요(출판사 안내에 따름).
- 사진은 자유 이용 사진(퍼블릭 도메인 · CC0 · 공공누리 제1유형 · CC BY · CC BY-SA)만 썼고, 각 차시 제목 화면의 **사진 출처**에 원저작자와 이용 조건을 밝혔어요.
- 그 밖의 그림은 직접 그린 그림이고, 글은 교과서 내용을 바탕으로 새로 썼어요.

## 파일
- `index.html` — 차시 목록 (우리 반 결과 · 선생님 설정 · 패드 안내)
- `T01.html`, `T07.html` … — 차시별 게임 (파일 하나만 열어도 실행돼요)
